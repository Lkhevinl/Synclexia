# Synclexia Privacy Policy

This repository contains the privacy policy for the Synclexia mobile application.

## About Synclexia

Synclexia is an educational mobile app designed to support children with dyslexia and learning differences. The app provides personalized learning experiences through reading activities, phonological awareness exercises, spelling practice, and adaptive AI-driven insights.

## Key Privacy Commitments

- ✅ **COPPA Compliant** - Special protections for children under 13
- ✅ **No Data Selling** - We never sell user data to third parties
- ✅ **Parental Control** - Parents can view, modify, and delete their child's data
- ✅ **Secure Storage** - Data encrypted in transit and at rest
- ✅ **Transparency** - Clear disclosure of data collection and usage
